Get started

  1. Install the Microsoft .NET 10 Desktop Runtime for your PC's architecture if Windows asks for it.
  2. Run the downloaded app. Open Battery controls and sign in with your battery control password. Open Farm settings and use your separate farm control password to review and change OpticsRE settings. Farm changes may remain queued; refresh to check the device state.
  3. Left-click the tray battery icon to open the dock. Use “Start with Windows” if you want it to run automatically. The dock also has an Uninstall button that removes the portable app file and its startup entry.
  4. Future releases download and install themselves after the app verifies their release signature and file checksum. You can also use “Check for updates” in the tray menu.

The app has a timestamped Windows signature from a local self-signed certificate. Windows on other PCs may still show an unverified publisher warning. You can verify the file against its SHA-256 value above. The tray app needs internet for live readings; Cloudflare continues logging while the PC is off.
