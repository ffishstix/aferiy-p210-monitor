Get started

  1. Install the Microsoft .NET 10 Desktop Runtime for your PC's architecture if Windows asks for it.
  2. Run the downloaded app. Public readings appear immediately. Open Battery controls and sign in with your control password to change device settings. The password is protected for your Windows account and is never included in the download.
  3. Left-click the tray battery icon to open the dock. Use “Start with Windows” if you want it to run automatically. The dock also has an Uninstall button that removes the portable app file and its startup entry.
  4. Future releases download and install themselves after the app verifies their release signature and file checksum. You can also use “Check for updates” in the tray menu.

The app is currently unsigned, so Windows may ask you to confirm the download. You can verify the file against its SHA-256 value above. The tray app needs internet for live readings; Cloudflare continues logging while the PC is off.
