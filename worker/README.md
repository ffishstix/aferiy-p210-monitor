# Cloud collector

This scheduled Cloudflare Worker logs into BrightEMS using account credentials, discovers the P210, gets vendor MQTT access, reads Modbus data over MQTT WebSocket, and stores the result in the website's D1 database once a minute. Opening the dashboard, starting the Windows app, and clicking its Refresh button also invoke the private `/check` route for a new saved reading. Its separate `/command` route accepts only server-authorised, allowlisted control requests and verifies each write with a fresh device read. It uses the cloud protocol described by [fossibot-ha](https://github.com/ldiogoz/fossibot-ha). A first real P210 reading was saved on 10 November 2026; the register values still need comparison with the phone app.

Required encrypted Worker secrets: `BRIGHTEMS_USERNAME`, `BRIGHTEMS_PASSWORD`, and `INGEST_SECRET` (for the private `/check` and `/command` endpoints). They are already installed in the owner's Cloudflare account. If the account controls multiple devices, configure `BRIGHTEMS_DEVICE_ID` to select the P210. The Local MQTT API token is not used. Run `npm ci`, `npm test`, and `npx wrangler deploy` from this directory after installing secrets. Never commit secrets to this repository.

The scheduled handler writes only after a valid Modbus response with a valid checksum and plausible charge %. Missing data produces no fake reading. The runtime figure is an unverified rough calculation from rated 2048 Wh capacity and current load. The first real response must be compared with the BrightEMS app before relying on status, ETA, or alerts.

The same schedule reads the farm OutBack system through the OpticsRE energy-flow endpoint. Set encrypted Worker secrets `OPTICS_USERNAME` and `OPTICS_PASSWORD`; system identifiers are in `wrangler.jsonc`. Its read-only collector stores solar output, generator state/power, battery voltage and signed power flow, and inverter load in `farm_telemetry`. Each vendor collection handles failures independently. The OpticsRE web API is not a published stable developer API, so verify collection after OpticsRE updates.

The farm has a MATE3s, VFX3048E inverter and two FM80 charge controllers, with no FLEXnet DC monitor. OpticsRE returns a zero battery percentage even though that reading is unavailable; the collector stores `NULL`. Negative battery power means the bank is supplying loads. Generator running state is saved separately from its measured output.
